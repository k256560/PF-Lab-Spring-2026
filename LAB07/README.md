**OBJECTIVES**
 Loops allow you to iterate through collections (like arrays or linked lists) and process every element without writing repetitive code for each one.
 They provide a mechanism to continue tasks only as long as specific conditions are met, ensuring the program halts once the goal is reached.
 Loops drastically reduce code complexity and line count by replacing manual repetition with a clean, logical structure.
 They support event-driven programming by enabling continuous checks for user inputs or system triggers in persistent applications.
Through statements like break and continue, loops offer precise control over when a process should skip an iteration or terminate entirely.
